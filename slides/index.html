第四段｜為什麼一隻 Agent 不夠

只用一個 Agent、用聊天推進，哪裡會壞？要改成什麼？

用 AI 的四種方式

方式誰決定步驟狀態存在哪怎麼知道做完換 Session 之後
一問一答人逐步提問對話人看回覆新對話重說
Agentic Workflow固定 SOP流程執行記錄流程走完依流程記錄接續
AI AgentAgent 自行決定Agent contextAgent 回報依 context 保存方式
Work-driven 多 Agent工作流與角色分工GitHub 工件Review／QA／接受讀票接手

Work-driven 結合固定流程的可控與 Agent 的彈性。

概念參考（出處待補）

一個 Agent 做全部 vs 分給多個 Agent
