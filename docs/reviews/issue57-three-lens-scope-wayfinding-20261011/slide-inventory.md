P098 [APP] 測試全綠，也可能什麼都沒驗到
  測試全綠，也可能什麼都沒驗到 教學偽碼｜假設錯誤實作在單向 Like 時也產生配對 無效測試也會綠 actual = match(單向 Like) assert actual == actual 拿結果和自己比，當然相同。 複製實作邏輯算預期，也可能一起錯。 獨立預期會抓到錯誤 actual = match(單向 Like) assert actual == 不配對 預期來自已確認的規則。 錯誤行為應讓測試失敗。 修正無效測試，確認它能抓到錯誤；不能刪掉失敗測試來換綠燈。
