教學偽碼｜假設錯誤實作在單向 Like 時也產生配對

無效測試也會綠

actual = match(單向 Like)
assert actual == actual

拿結果和自己比，當然相同。

複製實作邏輯算預期，也可能一起錯。

獨立預期會抓到錯誤

actual = match(單向 Like)
assert actual == 不配對

預期來自已確認的規則。

錯誤行為應讓測試失敗。

修正無效測試，確認它能抓到錯誤；不能刪掉失敗測試來換綠燈。

架構六層：一張 #3 如何被交接

4｜Orchestrator依目前狀態，把 #3 交給 Developer Agent。
5｜Execution RuntimeDeveloper Agent 實作 #3，提交 commit 並開 PR。
6｜Review / QA / HumanReview 與 QA 留下證據；Human Gate 核准後才 merge、進 Done。
